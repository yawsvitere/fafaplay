# FafaPlay

Минималистичный аудиоплеер на Rust. Сейчас проект умеет воспроизводить один аудиофайл через устройство вывода по умолчанию; структура оставляет место для добавления интерфейса и управления очередью.

## Запуск

```powershell
cargo run -- "C:\путь\к\музыке.mp3"
```

Для release-сборки:

```powershell
cargo build --release
```

Декодирование форматов MP3, FLAC, OGG Vorbis и WAV обеспечивает Rodio. Для сборки требуется установленный Rust toolchain.
